## กติกา
 - มีการตั้งชื่อผู้เล่นแต่ละคน จะต้องมีผู้เล่น 1 คนทำการสร้างห้อง และคนอื่นๆ จะเข้าร่วมผ่าน IP Address และจะต้องมีผู้เล่นมากกว่า 3 คนขึ้นไปจึงจะทำการเริ่มเกมได้ 
 - เกมจับเวลาการเล่น 15 วินาทีต่อคำ ผู้เล่นจะต้องพิมพ์ตามคำศัพท์ให้ถูกต้อง ถ้าพิมพ์ผิดจะถือว่าล้มเหลวและจะข้ามไปคำถัดไปทันที การเล่นเกมเราจะเล่น 20 คำ
ไต่ระดับ จาก เริ่มต้น -> กลาง -> ยาก -> ยากมาก ระดับละ 5 คำ
 - โดยคะแนนจะวัดจาก เวลา ยิ่งผู้เล่นใช้เวลาในการพิมพ์น้อยก็จะได้รับคะแนนมาก
คะแนน = คะแนน + (เวลาส่งคำตอบ * 10)
 - คำศัพท์จะถูกแบ่งหมวดหมู่ไว้สำหรับแต่ละระดับ (เริ่มต้น, กลาง, ยาก, ยากมาก) 
หมวดหมู่ละ 20 คำ ซึ่งโปรแกรมจะทำการสุ่มคำให้ผู้เล่นแต่ละคนตามระดับความยากของผู้เล่นในตอนนั้น ผู้เล่นที่ตอบไปแล้วจะผ่านไปคำถัดไปทันทีโดยไม่รอผู้เล่นคนอื่นๆ และเมื่อมีผู้เล่นเล่นจบเกมก่อน ก็จะต้องรอผู้เล่นคนอื่นๆ ในหน้า Leaderboard เพื่อรอสรุปคะแนน
